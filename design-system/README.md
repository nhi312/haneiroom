# Hanei Room

## design-system/

The HaneiRoom design system, exported 18 Oct 2026.

- `index.html`: open in a browser for a visual overview of everything below.
- `README.md`: the brand book (logo rules, voice, color, type, layout, desktop app patterns, icon, sticker and texture rules).
- `tokens.css` / `tokens.json`: every color, type style, spacing, radius and shadow value. Link `tokens.css` in any page to use the `--navy-700`-style variables and the `.display`, `.h1`… type classes.
- `logo/`: the HaneiAi logo (transparent and on-white PNG, 655×293).
- `icons/`: 25 rounded line icons (SVG, 24px, navy).
- `stickers/`: 9 brand stickers (SVG).
- `textures/`: 3 gradients, palm pattern, palm shadow, grain and paper (SVG).
- `components/`: Button, Chip, ProjectCard, SidebarNav and the cover as standalone HTML, each with a .md usage note.
